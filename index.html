CURSO 03 / OFIMÁTICA
Trabaja inteligentemente

Herramientas ofimáticas

01Documentos
02Cálculos
03Presentaciones

CURSO 04 / DESARROLLO WEB
Construye tu primera web

Creación de páginas web

Aprende cómo se construyen los sitios web y desarrolla tu primera página desde cero. Combina estructura, diseño e interactividad con tecnologías web.

01HTML
02CSS
03JavaScript

Lo que aprenderás

Estructura con HTML

Agrega títulos, textos, imágenes y enlaces.

Diseño con CSS

Personaliza colores, espacios, tarjetas y botones.

Interactividad

Utiliza JavaScript para añadir funciones a tu página.

Tu reto práctico

Construye una página personal con navegación, imágenes y estilos propios.
